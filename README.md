# Autumn SPA 2026

Live shortlist for a 24–31 October 2026 holiday in Ukraine.

The site is intentionally static: presentation lives in `index.html`, `styles.css` and `app.js`; hotel data lives in `hotels.json` so rankings and prices can be updated independently.

## Scenarios
- 2 adults
- 2 adults + child (10)

## Publishing
Enable GitHub Pages from the `main` branch, root (`/`).
